

\# PLP Week 7 - Learner Report Builder



\## Project Description

This Python project reads learner information from a CSV file and generates a learner performance report.



\## Project Files

\- hubs.csv - Contains learner names, hubs and scores.

\- report\_builder.py - Python program that processes learner records.

\- report.txt - Generated learner performance report.

\- my\_notes.py - Python practice notes.

\- my\_notes.txt - Additional learning notes.



\## Features

\- Reads CSV files using Python's csv module.

\- Calculates total learners.

\- Counts learners who passed and failed.

\- Calculates the average score.

\- Generates a text report.

\- Handles missing CSV files using try and except.



\## Passing Criteria

A learner passes if their score is 50 or above.



\## How to Run

1\. Make sure Python is installed.

2\. Open PowerShell in the project folder.

3\. Run:



&#x20;  python report\_builder.py



4\. View the generated report:



&#x20;  Get-Content report.txt
